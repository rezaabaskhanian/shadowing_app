# پنل ادمین شادوئینگ (Next.js)

پنل مدیریت صحنه‌ها، هات‌اسپات‌ها و دیالوگ‌ها برای اپلیکیشن شادوئینگ.
ادمین می‌تواند تصویر پس‌زمینه آپلود کند، روی تصویر نقاط هات‌اسپات بگذارد و برای هر
هات‌اسپات چند دیالوگ (با متن انگلیسی، ترجمه و **فایل صوتی/ویس**) تعریف کند.

## پیش‌نیاز
- بک‌اند Go در حال اجرا روی `http://localhost:8088`
- Node.js نسخه ۱۸ به بالا

## راه‌اندازی
```bash
cd admin-panel
npm install
npm run dev
```
سپس مرورگر: **http://localhost:3000**

> آدرس بک‌اند در فایل `.env.local` تنظیم می‌شود:
> `NEXT_PUBLIC_API_URL=http://localhost:8088`
> (پورت‌های 3000 و 3001 در CORS بک‌اند مجاز هستند.)

## ورود ادمین
کاربر ادمین پیش‌فرض توسط migration شماره `006_seed_admin_user.sql` ساخته می‌شود:
- شماره تلفن: `09000000000`
- رمز عبور: `admin123`

فقط کاربرانی با نقش `admin` اجازه‌ی ورود به پنل و فراخوانی APIهای `/v1/admin/*` را دارند
(احراز هویت JWT + میدل‌ور `AdminOnly`).

## قابلیت‌ها
- **ورود با نقش ادمین** — توکن JWT در localStorage نگهداری می‌شود.
- **ساخت صحنه**: عنوان، توضیح، سطح سختی، آپلود تصویر پس‌زمینه.
- **هات‌اسپات دستی**: با کلیک روی تصویر، نقطه اضافه می‌شود (مختصات به‌صورت درصد).
- **دیالوگ برای هر هات‌اسپات**: گوینده، متن انگلیسی، ترجمه، نوع نمایش، مدت انتظار،
  و **آپلود ویس** برای همان دیالوگ (با پیش‌نمایش پخش).
- **لیست صحنه‌ها**: نمایش صحنه‌ها، مشاهده‌ی جزئیات با نقاط روی تصویر و پخش صداها، و حذف.
